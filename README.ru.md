# Бег по рельсам (RailRunner)

[English](README.md) · **Русский**

Бесконечный 3D-бег по трём железнодорожным путям: прыгай через барьеры, ныряй под
перекладины, уходи от встречных поездов, забегай на крыши вагонов и собирай монеты.
Скорость растёт с каждым метром. Работает в браузере и как программа для Windows.

- **Играть в браузере:** https://alexalesha.github.io/RailRunner/
- **Скачать для Windows:** [последний выпуск](https://github.com/ALEXalesha/RailRunner/releases/latest) -
  `RailRunner-<версия>-Setup.exe` (установщик) или `RailRunner-<версия>-Portable.exe` (без установки)

Фан-игра в жанре «бег по путям». Графика, звуки и названия свои; с правообладателями
известных игр жанра не связана.

## Как играть

| Действие | Клавиатура (по умолчанию) | Палец или мышь |
| --- | --- | --- |
| Влево / вправо | ← → или A D | свайп влево-вправо, касание левой или правой трети экрана |
| Прыжок | ↑, W или пробел | свайп вверх, касание посередине |
| Подкат | ↓ или S | свайп вниз |
| Пауза | P или Esc | кнопка в левом верхнем углу |

- **Барьер** (красно-белый, низкий) - перепрыгнуть.
- **Перекладина** (жёлто-чёрный щит со стрелкой вниз) - пролезть подкатом.
- **Поезд** - объехать по соседнему пути. На поезд с пандусом можно забежать и бежать по крыше.
- **Встречный поезд** с горящими фарами едет навстречу и гудит - уходи с его пути заранее.
- **Удар боком** отбрасывает на прежний путь, игрок спотыкается; второй удар за это время - конец забега.
- Подкат в воздухе - быстрое падение; прыжок, нажатый чуть раньше приземления, срабатывает при приземлении.
- Все клавиши переназначаются в настройках (у каждого действия три места), подсказки в игре
  всегда называют те клавиши, которые назначены сейчас.

### Ускорители

| | Что делает | Сколько длится |
| --- | --- | --- |
| Магнит | притягивает монеты со всех путей | 10 с |
| Двойные очки | очки за метры и монеты вдвое | 12 с |
| Ботинки-прыгуны | прыжок выше поезда | 10 с |
| Ховерборд | спасает от одной аварии (потом короткая неуязвимость) | 30 с |

Монеты копятся между забегами. За них покупаются **улучшения**: каждый уровень (до пятого)
удлиняет ускоритель на 20 %. Цены: 150, 300, 600, 1200, 2400.

### Что ещё

- Темы: как в системе, светлая (день) и тёмная (ночь с огнями в окнах).
- Русский и английский; по умолчанию - язык браузера.
- Звук и музыка синтезируются на лету (Web Audio), файлов со звуками нет. Громкость музыки и
  звуков - отдельными ползунками.
- Рекорд, монеты, улучшения и настройки сохраняются (в браузере - в его хранилище под ключом
  `railrunner:save`, в программе - в её папке данных).
- Пауза сама включается, если окно свернули или вкладку скрыли; продолжение - после отсчёта 3-2-1.
- Графика «Красивая» или «Быстрая» (для слабых ноутбуков), счётчик кадров в настройках.
- Программа для Windows запоминает размер и место окна; F11 - во весь экран.

## Программа для Windows

Установщик ставит игру для текущего пользователя (права администратора не нужны), ярлыки на
рабочем столе и в «Пуске». Тихая установка: `RailRunner-<версия>-Setup.exe /S`.
Portable-версия запускается без установки.

## Для разработчика

Всё лежит в репозитории, во время игры из сети ничего не грузится: three.js 0.170.0 (MIT)
лежит в `web/vendor/three.js` обычным скриптом, поэтому страница работает и с диска (`file://`).

```
web/index.html      страница
web/js/core.js      правила игры без экрана и клавиатуры: генератор, физика, столкновения, очки
web/js/render.js    3D-вид (three.js), только рисует
web/js/app.js       экраны, клавиши, свайпы, сохранение, игровой цикл
web/js/audio.js     звуки и музыка синтезом
web/js/i18n.js      тексты RU/EN
electron/           оболочка программы для Windows
tests/unit/         законы правил (node:test)
tests/web/          сценарии игрока в headless Chromium (Playwright)
tests/app/          законы программы на Electron (окно в тестах невидимо)
tools/mutate.js     проверка проверок: ломает правила по одному, законы обязаны упасть
```

```
npm ci
npm test            # 33 закона правил, ~25 с
npm run test:web    # 19 сценариев страницы, ~3 мин
npm run test:app    # 3 закона программы, ~1 мин
npm run mutate      # 26 мутантов, ~10 мин
npm run screens     # кадры для README
npm run dist        # dist/RailRunner-<версия>-Setup.exe и -Portable.exe
```

**Почему всегда есть путь.** Мир строится рядами. В каждом ряду у генератора есть
«безопасный» путь: на нём только то, что можно пройти (ничего, барьер, перекладина или поезд с
пандусом). Безопасный путь сдвигается не больше чем на один путь за ряд и только туда, где
свободно заранее - за время смены пути плюс реакцию. Встречные поезда двигаются в долях
скорости игрока, поэтому место встречи генератор знает точно. Это проверяют два независимых
закона: проверка готового мира (300 миров по 4 км) и автопилот с настоящей физикой, который
проходит 4 км на 60 мирах. Тот же автопилот бежит в меню за экраном.
